Feeds and API

Subscribe in a feed reader to get new titles without visiting this page. Add ?publisher=WILEY (or SPRINGER, ELSEVIER, IEEE, ACM) to limit a feed to one publisher.

  • Atom feed of change events
  • RSS feed of newly added titles

JSON endpoints:

  • /api/publishers – overview per publisher
  • /api/events?since=YYYY-MM-DD&publisher=&work_type=&type=title.added – change events
  • /api/publications?publisher=&type=&year=&query=&limit= – search
  • /api/publications/new?since=YYYY-MM-DD&publisher= – titles added since a date
Data source: CrossRef. “New” means newly registered in CrossRef, which can be later than the publisher’s own announcement.
